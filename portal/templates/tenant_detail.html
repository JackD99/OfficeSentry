One-time setup required before this step.

Microsoft Graph PowerShell requires a custom Entra app registered in your management tenant to show the device-code login prompt. Without it, Windows will silently reuse your own cached session and fail.

Do this once in your management tenant (your MSP's own tenant):

  1. Go to Entra ID → App registrations → New registration
  2. Name: Office Sentry Admin Connector
  3. Supported account types: Accounts in any organizational directory (Multi-tenant)
  4. No redirect URI — click Register
  5. Open the app → Authentication → Advanced settings
  6. Set Allow public client flows → Yes and save
  7. Copy the Application (client) ID
  8. Go to Settings → Admin Connector App and paste it

The connector app needs no API permissions — it requests them from the client admin at sign-in time.
