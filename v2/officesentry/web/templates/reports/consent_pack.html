Step 2: give it the Global Reader role

Microsoft only shows mailbox settings, such as forwarding, to an app with an admin role. Global Reader is Microsoft's built-in role that can view settings but can't change any of them, and it can't open anyone's email.

  1. Sign in to the Microsoft Entra admin centre, {{ cloud.admin_centre.split('//')[-1] }}, as a Global Administrator.
  2. Go to Roles and admins, open Global Reader and choose Add assignments.
  3. Select {{ app }} and add it.

This step is optional: without it, only the mailbox reports stay empty.

Office Sentry connects as an app with a certificate {{ brand.display_name }} holds, not with anyone's password. Every request it makes to Microsoft 365 is a read; the Exchange commands it may run all start with Get-.

Removing the access

You can take it away at any time, and it stops straight away. In the Microsoft Entra admin centre:

  1. Roles and admins → Global Reader: select {{ app }} and choose Remove assignments.
  2. Enterprise applications: open {{ app }}, choose Properties, then Delete.
