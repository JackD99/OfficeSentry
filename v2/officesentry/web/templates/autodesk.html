What Office Sentry reads from Autodesk

For each client you give an Autodesk team, every night:

  • Its subscriptions: product, seats bought and assigned, status, start and end dates.
  • Who holds a seat of each product, when it was assigned, and when they last used it in the last 90 days.

It never reads designs, files, projects or anything else in Autodesk, and it can't change a user, a seat or a setting: Autodesk has no API for those. A team whose admin hashes personal data in Autodesk Account shows codes instead of names.

Every request reads, except two the Reporting API needs: token signs in as the app, and export asks Autodesk to prepare one team's report files, which Office Sentry then downloads. Every export names the client's own team, and neither changes anything in the client's Autodesk account.
