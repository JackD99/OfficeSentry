{{ icon('doc') }} Get help in three steps

  1. Check the usual causes. System status says whether the worker, collection, backups and disk are fine; Troubleshooting covers the setup and sign-in errors people meet most.
  2. Download the support package (left). It carries the version, settings, health, recent failures and logs, so nobody has to ask for them one by one.
  3. Open a bug report on GitHub: what you did, what you saw and what you expected, the reference from the error page if there was one, and the zip attached. Issues are public; the package is written for that.

Found a security problem? Don't post it: use private vulnerability reporting. More in Getting help.
