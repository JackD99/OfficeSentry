Other ways to create the app

From the server's command line. With Docker, run docker compose run --rm worker python -m officesentry create-app (add --cloud gcc_high, dod or china for those clouds). Without Docker, run python -m officesentry create-app. It does the same as the button above.

By hand in the Entra admin centre, if your Conditional Access blocks device sign-in:

  1. Generate a certificate here{% if show_generate %} (below){% endif %}, then download its .cer file.
  2. In the Entra admin centre: App registrations → New registration. Supported account types: Accounts in any organizational directory.
  3. Redirect URI (Web): {{ redirect_uri }}. Without it, the consent link fails with error AADSTS50011.
  4. Under Certificates & secrets, upload the .cer file. Under API permissions, add the application permissions listed at the bottom of this page.
  5. Copy the app's Application (client) ID into the connection on this page.
