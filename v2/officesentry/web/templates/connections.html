App connections

Office Sentry signs in to client tenants as one multi-tenant, read-only Entra app. Create it once:

  1. Generate a certificate below. The private key stays encrypted in Office Sentry's database.
  2. Create the app, either with python -m officesentry create-app (does steps 2 and 3 for you) or by hand in your own tenant's Entra admin center: App registrations → New registration, supported account types "Accounts in any organizational directory", redirect URI (Web) {{ redirect_uri }}. Upload the .cer under Certificates & secrets and add the application permissions listed below.
  3. Save the app's Application (client) ID here.
  4. Add each client tenant and send its admin the consent link shown on the tenant page.
  5. For Exchange reports (forwarding, mailbox permissions, shared mailboxes), the tenant admin also assigns the Global Reader role to the app in that tenant: Entra admin center → Roles and admins → Global Reader → Add assignments. Global Reader can't change anything.
