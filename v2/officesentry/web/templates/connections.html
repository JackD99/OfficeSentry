App connection

Office Sentry signs in to every client tenant as one multi-tenant, read-only Entra app. You set it up once (once per Microsoft cloud, if you have clients in GCC High, DoD or China).
  1. Generate a certificate
    The private key is created and kept encrypted inside Office Sentry. It never leaves it. {% if not connections %}
    {{ csrf() }}
    {% endif %}
  2. Create the app in your own Entra tenant
    Easiest: run python -m officesentry create-app on the server. It registers the app, uploads the certificate and adds the permissions.
    Or do it by hand
    1. In the Entra admin center: App registrations → New registration.
    2. Supported account types: Accounts in any organizational directory.
    3. Redirect URI (Web): {{ redirect_uri }}. Without it, the consent link fails with error AADSTS50011.
    4. Under Certificates & secrets, upload the .cer file below.
    5. Under API permissions, add the application permissions listed at the bottom of this page.
  3. Save the app's client ID
    Copy the Application (client) ID from the app's overview page into the form below. Add the Directory (tenant) ID from the same page too, and Office Sentry checks the certificate works straight away.
  4. Add client tenants
    Each tenant gets a consent link for its Global Administrator. For mailbox reports they also give the app the read-only Global Reader role. {% if ready %}
    {{ icon('plus') }} Add a tenant Every client's consent, permissions and Global Reader
    {% endif %}

Replacing the certificate

Collection keeps using the current certificate until you switch, so nothing stops in between.

  1. New certificate made
    {{ c.next_thumbprint }}, valid until {{ c.next_not_after|day }}.
  2. Add it to the app registration, next to the old one
    In the Entra admin centre{% if not cloud_of(c).is_default %} ({{ cloud_of(c).admin_centre }}){% endif %}: App registrations → {{ c.name }} → Certificates & secrets → Certificates → Upload certificate, and choose the new .cer. Leave the old certificate there for now.
    {{ icon('download') }} Download new .cer
  3. Test it
    {% if tested %}Signed in with the new certificate {{ ts(c.next_checked_at) }}.{% else %}Office Sentry signs in with the new certificate and reads the tenant's name. Nothing is changed. A newly uploaded certificate can take 5 to 10 minutes to work.{% endif %}
    {{ csrf() }}
  4. Switch to it
    Collection signs in with the new certificate from then on. Afterwards you delete the old one from the app registration.
