App connection

Office Sentry signs in to every client tenant as one multi-tenant, read-only Entra app. You set it up once.
  1. Generate a certificate
    The private key is created and kept encrypted inside Office Sentry. It never leaves it. {% if not connections %}
    {{ csrf() }}
    {% endif %}
  2. Create the app in your own Entra tenant
    Easiest: run python -m officesentry create-app on the server. It registers the app, uploads the certificate and adds the permissions.
    Or do it by hand
    1. In the Entra admin center: App registrations → New registration.
    2. Supported account types: Accounts in any organizational directory.
    3. Redirect URI (Web): {{ redirect_uri }}. Without it, the consent link fails with error AADSTS50011.
    4. Under Certificates & secrets, upload the .cer file below.
    5. Under API permissions, add the application permissions listed at the bottom of this page.
  3. Save the app's client ID
    Copy the Application (client) ID from the app's overview page into the form below. Add the Directory (tenant) ID from the same page too, and Office Sentry checks the certificate works straight away.
  4. Add client tenants
    Each tenant gets a consent link for its Global Administrator. For mailbox reports they also give the app the read-only Global Reader role. {% if ready %}
