{% elif plan.reason == 'updater_off' %}

Turn on the Update button

Installing a release is done by the updater, a small extra container you turn on once. It is the only part of Office Sentry given access to Docker; the portal never is.

  1. In the folder with docker-compose.yml, add COMPOSE_PROFILES=updater to .env (with a comma between profiles if you use others, such as updater,https).
  2. If your docker-compose.yml came with a release before 2.3.0, download the one attached to the newest release, which has the updater in it.
  3. Run docker compose up -d. This page offers the button within a minute.

The Update button has the details. Running it under Portainer, another container manager, a NAS or Kubernetes? The button isn't for those: update the way its guide says.

{{ icon('doc') }} Updating by hand

Always works, with or without the updater. In the folder with docker-compose.yml:

  1. read the release's notes, above all Action required;
  2. set the version in .env: OFFICESENTRY_VERSION={{ target.version if target else '' }};
  3. run docker compose pull and docker compose up -d.

Updating and Rolling back an update have the details.
